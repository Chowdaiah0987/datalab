app.put("/api/profile/logo", wrap(async (req, res) => {

  const profile = await Profile.findOneAndUpdate({ key: "main" }, { logo }, { new: true, upsert: true, setDefaultsOnInsert: true });

4) Make Home the default page (server.js, "Website files" section at the bottom)
   Replace:

     app.use(express.static(__dirname, { index: "home.html" }));
     ...res.sendFile(path.join(__dirname, "home.html"))...
